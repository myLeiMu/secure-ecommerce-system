Redis 错误率验收：通过。
Redis 跨 Windows/WSL 访问有额外通信成本，单进程低并发下不保证比进程内缓存更快；其共享缓存能力适用于多个后端进程，此处未做多进程容量测试。
原第九周旧版→优化版的 20% 改善验收保持不变；本表仅补充缓存后端选择的数据，不混用两种实验计算提升。
两组按顺序实测，机器和 MySQL/Redis 实例与其他服务共享，不能据此断言微小差异具有统计显著性。
