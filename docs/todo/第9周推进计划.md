## 5. 卡点与帮助

已完成：正式前后各三轮、每接口每组 150 样本；登录、商品查询、下单 p95 分别降低 99.30%、99.43%、98.32%，优化后三接口错误率均为 0%。同环境核验通过，第 2/4 周及新增正确性回归通过；本机两个新增索引已迁移，用户按启动说明重启后端后加载新版代码。

最初隔离启动缺少日志目录、健康检查要求未启用的 Redis，已修正压测夹具；旧版实际并发登录出现 MySQL 死锁，原始错误保留。一次运行被中断，完整轮次保留，部分轮次归档后按同一指纹重跑。完整结果以最终报告为准。

本实验是本机回环 API + MySQL 的固定课堂负载，不声称生产最大容量或 nginx/mTLS 端到端成绩。若教师要求指定更高并发或真实网关负载，需要在新的固定环境补测；不能取消限流或降低口令迭代成本来凑数据。
